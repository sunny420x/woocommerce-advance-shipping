## จัดการค่าบริการขนส่ง ##
ระบบกำหนดค่าบริการขนส่ง ตัวเลือกบริษัทขนส่งสำหรับลูกค้า และตัวเลือกการรับหน้าร้าน สำหรับสินค้าบน WooCommerce รองรับการคิดค่าบริการขนส่งแบบขั้นบันใดของไปรษณีย์ไทย รองรับการกำหนดค่าขนส่งแบบคงที่จะสำหรับหมวดหมู่ของสินค้าบางหมวดหมู่ รองรับการบวกค่าแพ็คสินค้า และค่าธรรมเนียมเพิ่มเติมตามรหัสไปรษณีย์ เช่น พื้นที่ห่างไกลและพื้นที่ยากลำบาก โดยตั้งค่ารหัสไปรษณีย์แยกจากกันได้

เมนู **แก้ไขน้ำหนักด่วน** ช่วยค้นหาและแก้ไขน้ำหนักของสินค้าหลักและสินค้าย่อยหลายรายการได้จากหน้าเดียว โดยเลือกสินค้า ตรวจสอบน้ำหนักปัจจุบัน และกำหนดน้ำหนักใหม่ในช่องเดียวเพื่ออัปเดตสินค้าที่เลือก หน่วยน้ำหนักเป็นไปตามการตั้งค่า WooCommerce

## วิธีติดตั้งปลั้กอิน ##
ไปที่ <code>/wp-admin/plugin-install.php</code> และอัปโหลดไฟล์ zip ของปลั้กอิน จากนั้นสามารถ <b>Activate</b> แล้วเริ่มใช้งานปลั้กอินจากเมนูได้เลย !
